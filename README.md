# Sistema de Bordado v3

## Flujo
1. Recepcion del trabajo (vale/proyecto, quien entrega, piezas)
2. Bordados del proyecto (1 o mas, boton agregar)
3. Asignacion a 1..N operadores y maquinas
4. Operador reporta tiempos, piezas e incidencias
5. Trazabilidad + productividad por operador/maquina
